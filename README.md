# Fullstack Lab 2 — Personal Portfolio

Адаптивная личная страница-визитка по материалам лекции 2 «HTML5 и семантическая вёрстка, CSS3 — Flexbox, Grid, адаптивность».

## Что реализовано

- Семантические теги HTML5: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- Отдельный CSS-файл и базовые селекторы.
- Box model и `box-sizing: border-box`.
- Flexbox для навигации, кнопок и контактного блока.
- CSS Grid для карточек навыков и проектов.
- Адаптивная вёрстка с mobile-first media queries.
- Meta viewport для корректного отображения на мобильных устройствах.
- Разделы «Обо мне», «Навыки», «Проекты» и «Контакты».

## Структура проекта

```text
fullstack-lab2/
├── index.html
├── css/
│   └── style.css
└── README.md
```

## Как запустить

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере.

Сборка и установка зависимостей не требуются.

## Что персонализировать перед сдачей

- Замените имя «Алекс» на своё.
- Укажите актуальный email и ссылку на GitHub.
- Измените описание, навыки и проекты под себя.

## GitHub Pages

Чтобы опубликовать сайт: откройте **Settings → Pages**, выберите публикацию из ветки `main` и папки `/ (root)`, затем сохраните настройки.
